Core Architecture at a Glance

Six Layers of Defense Between Your Records and the Cloud

Every security boundary works independently—so even if one layer is stressed or offline, customer identities and keys remain mathematically out of reach.

O(1)-RAM Streaming Tokenizer

Scrubs names, National IDs, IBANs, and IPs line-by-line into TOK_<16-hex> without loading whole batches into RAM.

line stream → ~64 KiB buffer → TOK_bd40...

Chunked BVL3 AEAD & 64 KiB Padding

Fixed 65,536-byte AES-256-GCM frames with per-chunk nonces and CSPRNG noise padding prevent file-size traffic inference.

Frame 0 Frame 1 64 KiB Pad

Offline 2-of-3 Ed25519 Quorum

Gateway stores only officer *.pub keys; unmasking requires 2 offline signatures bound to a single-use nonce and UTC expiry.

Officer 1 ✓ Officer 2 ✓ No .priv on host

PKCS#11 HSM & RFC 3394 Wrapping

Non-extractable Master KEK (CKA_EXTRACTABLE=FALSE) wraps per-batch DEKs with crash-safe KEK rotation and RAM zeroization.

DEK ──RFC 3394──▶ HSM Chip

2-of-3 XOR Erasure Shards

Splits ciphertext across local disk or 3 S3/MinIO buckets (AWS SigV4) with automatic SHARD_RECOVERY if a cloud node fails.

s0 s1 s2 Any 2 = 100%

Mutual TLS 1.3 & Qt 6 Console

Strict SHA-256 certificate fingerprint allowlisting plus a 3-tab desktop operations console (BlindVault_GUI).

BlindVault-Control: Reach Peers Anywhere Without Surrendering Privacy

Pair sending and receiving BlindVault nodes behind home or office firewalls using an 8-character invite code. blindvault-control discovers your external address, introduces peers via ephemeral Redis state, and relays locked TLS 1.3 streams if direct TCP is blocked—without ever logging files, histories, or keys.

Developer & Operator Quickstart

Up and Running in Minutes

Choose your workflow below—from core mTLS transfers and offline compliance quorum ceremonies to HSM hardware keys and the Qt 6 desktop app. 

# 1. Build BlindVault CLI & test suite (Ubuntu 24.04 / WSL2)
git clone https://github.com/OmarAhmedTHE25th/BlindVault.git
cd BlindVault
cmake -S . -B build -G Ninja
cmake --build build

# 2. Initialize EC P-256 identities & pin peer fingerprints
./build/BlindVault init gateway_node
./build/BlindVault fingerprint
./build/BlindVault trust add <PEER_SHA256_FINGERPRINT> cloud_vault

# 3. Transfer over mutual TLS 1.3 (direct or via blindvault-control)
./build/BlindVault receive 8080 ./cloud_received
./build/BlindVault send 127.0.0.1 8080 ./payload.enc
# 1. Generate offline Ed25519 keypairs for 2-of-3 Compliance Officers
./build/BlindVault officer-keygen CBE-Officer-1 ./offline_officers
./build/BlindVault officer-keygen CBE-Officer-2 ./offline_officers
cp ./offline_officers/*.pub ./bank_state/officers/

# 2. Stream CSV through Tokenizer + 64 KiB BVL3 AEAD + 2-of-3 Shards
./build/BlindVault vault offload batch.csv --state-dir ./bank_state --cloud-dir ./cloud_bucket

# 3. Issue a replay-proof challenge (16B nonce + 5m expiry), sign offline, and query
./build/BlindVault vault challenge "Ahmed Hassan" --state-dir ./bank_state
SIG1=$(./build/BlindVault officer-sign ./offline_officers/CBE-Officer-1.priv CBE-Officer-1 <TOKEN> <BLOB> <WDEK> <NONCE> <EXPIRES>)
SIG2=$(./build/BlindVault officer-sign ./offline_officers/CBE-Officer-2.priv CBE-Officer-2 <TOKEN> <BLOB> <WDEK> <NONCE> <EXPIRES>)
./build/BlindVault vault query "Ahmed Hassan" ./cloud_bucket --nonce <NONCE> --expires <EXPIRES> \
  --approval "CBE-Officer-1:$SIG1" --approval "CBE-Officer-2:$SIG2" --state-dir ./bank_state
# Attach a PKCS#11 Hardware Security Module or SoftHSMv2 token (non-extractable KEK)
export BLINDVAULT_PKCS11_MODULE=/usr/lib/softhsm/libsofthsm2.so
export BLINDVAULT_PKCS11_PIN=1234

# Launch 3 independent MinIO buckets for AWS SigV4 2-of-3 erasure sharding
docker compose -f docker-compose.vault.yml up -d
export BLINDVAULT_SHARD0_URL=http://127.0.0.1:9000/blindvault-shard0
export BLINDVAULT_SHARD1_URL=http://127.0.0.1:9002/blindvault-shard1
export BLINDVAULT_SHARD2_URL=http://127.0.0.1:9004/blindvault-shard2
export AWS_ACCESS_KEY_ID=minioadmin
export AWS_SECRET_ACCESS_KEY=minioadmin

./build/BlindVault vault offload batch.csv --state-dir ./bank_state --cloud-dir ./cloud_bucket
# Install Qt 6 development packages & compile the 3-tab desktop console
sudo apt install -y qt6-base-dev libgl1-mesa-dev
cmake -S . -B build-gui -G Ninja -DP2P_BUILD_GUI=ON -DP2P_BUILD_TESTS=OFF
cmake --build build-gui --target BlindVault_GUI

# Launch BlindVault Qt 6 RegTech Operations Console
./build-gui/BlindVault_GUI
